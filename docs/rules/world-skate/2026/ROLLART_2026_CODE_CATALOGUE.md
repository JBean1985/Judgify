## 6. Code Normalization Rules
Proposed Judgify canonical code record format (for future import, no renaming):
- Official code preserved exactly (`codeOfficial`)
- Normalized type (`typeNormalized`): `jump` | `spin` | `step sequence` | `choreographic sequence` | `other`
- Normalized family (`familyNormalized`)
- Normalized rotations (`rotationsNormalized`): integer or null
- Normalized level (`levelNormalized`): `Base`, integer, or null
- Original source label retained (`officialDisplayedName`)
- Traceability retained (`sourceId`, `pdfPage`, `tableSection`)

Normalization principles:
- Do not alter official code casing (`Br`, `In`, `CBD`, etc.).
- Do not convert call-modifier columns into standalone element codes.
- Keep unresolved/unclear rows flagged as `requires clarification` until rechecked on PDF view.
